# Frontend milestone 1 — completed 2026-09-13

The React analyst workspace is running at **http://127.0.0.1:5173** in the
development Compose project. The initial account is stored in the owner-only
`.local/admin-credentials.json` file. The frontend contains no embedded credentials.

Implemented:

- Login/logout, expiring sessions, role display, and password change.
- Live dashboard counts, hourly chart, severity distribution, recent alerts,
  telemetry sources, and detection-worker state.
- Event and alert explorers with exact server filters and cursor pagination.
- Event detail and plain-text raw telemetry.
- Investigation evidence, status, assignment, notes, and paginated audit history.
- Stale-edit recovery, retained draft notes during reload, and idempotent note retry.
- Host inventory/detail and detection-rule coverage views.
- Responsive navigation with keyboard support and bounded scrolling tables.
- Explicit loading, empty, connection-error, and expired-session states.
- Production build, same-origin API proxy, nested routes, security headers,
  container health checks, and documented development commands.

## Remaining scope

Sessions are held only in memory, so browser refresh requires sign-in again.
Unsubmitted drafts are not saved when leaving an investigation. User management,
endpoint enrollment/key-management screens, saved searches, exports, notifications,
persistent login/SSO, and public HTTPS frontend hosting are later milestones.

The separate hardened HTTPS stack remains API-only and recovered healthy after
Docker was restarted during this work. Native Windows VM validation and periodic
collector heartbeat scheduling remain deferred.
